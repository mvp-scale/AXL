“Make it more polished” is not an instruction. This is.

Pick a design word. AXL shows what it measurably means, fixes the page with it, and proves the result with a command you can re-run.

How a vague word becomes a check

  1. 1

    The word

    “Polish it.” Every tool defines it differently, or not at all.

  2. 2

    A definition

    A short list of things a machine can count: gaps on a 4px scale, text dark enough to read, buttons big enough to tap.

  3. 3

    A check

    A command returns pass or fail. It works on your page, not only on ours.

  4. 4

    A receipt

    The exact command, tool version and result are saved. Run it again and get the same answer, or the receipt is not valid.

A word with no measurable definition stays in the catalog, labelled that way. It never ships as a skill.
